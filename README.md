# CyberAid — Cyber Crime Help Knowledge Base

A responsive, neon-styled educational website that helps users choose a cybercrime situation and view a rule-based action checklist with official Indian reporting resources.

## Features

- Responsive dark neon UI with cyan/violet glow effects
- Searchable cybercrime categories
- Rule-based knowledge base for financial fraud, hacked accounts, phishing, cyberbullying, blackmail, identity theft, fake job/investment scams, device compromise, and unknown situations
- Step-by-step actions and evidence-preservation reminders
- Official resource links: National Cyber Crime Reporting Portal and CERT-In
- Print / Save checklist
- No backend required; the knowledge-base logic runs in the browser
- Does not ask for passwords, OTPs, PINs, or payment credentials

## Run locally

1. Download `index.html`.
2. Open it in a modern browser, or open the folder in VS Code and use a local preview extension.
3. No `pip install`, Node.js, API key, or database is required.

## Upload to GitHub

1. Create a new repository on GitHub, for example `cyberaid-knowledge-base`.
2. Upload `index.html` and this `README.md` to the repository root.
3. To publish it with GitHub Pages: open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site and open the URL shown in Settings → Pages.

## Important limitations

This is an educational prototype, not an official government website, police service, legal service, or automated investigation tool. It provides prewritten rule-based guidance and does not verify incidents, file complaints, contact banks, trace offenders, or guarantee recovery of money. Official websites and procedures can change, so users should confirm current instructions at the linked official resources.

For financial cyber fraud in India, contact your bank/payment provider immediately and call **1930** as soon as possible; follow the official portal's instructions to complete the report. In an immediate emergency, contact local emergency services (112 in India).
